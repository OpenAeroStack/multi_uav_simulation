                                           segfault -> duplicate address

7. tcpdump sees it, app does not           -> between interface and socket

================================================================================
 TRAPS
================================================================================

NCNN: never pass imgsz. It is fixed at export time. Passing imgsz=640 to a
      384x640 model gives correct boxes on call 1 and 13 garbage boxes at
      conf 0.88 on every call after. No error. yolo_detect_node.py now drops
      imgsz automatically for NCNN models.

imgsz is [height, width]. A single number means square.

Same rule for every export - OpenVINO, .mnn, .onnx. Only a .pt takes imgsz.
Both detectors now drop it automatically for anything else.

OpenVINO RAISES on a shape mismatch. NCNN does not - it returns a stable
wrong answer that looks plausible. Never trust NCNN counts without looking.

Pi 5 back-end rankings do not transfer. The Pi 4B's Cortex-A72 is ARMv8.0-A
and lacks i8sdot/fp16/i8mm, so MNN is SLOWER than NCNN here and FP16 gains
nothing. Benchmark on the actual board.

pkill -f gzserver kills your own terminal. Use -x.

install/ has uav_vision.  ros2/install/ has uav_controller. Not interchangeable.

mission must run inside gcsns or /uav1/arm is invisible.

detector must be running or the camera does not transmit at all.
